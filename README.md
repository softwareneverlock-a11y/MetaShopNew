# Meta Shop

Статический сайт онлайн-вейпшопа Meta Shop.

## Структура

- `index.html` - разметка сайта.
- `style.css` - стили и адаптивная верстка.
- `script.js` - товары, новости, переключение категорий и Telegram-заказы.
- `images/` - изображения товаров.

## Как добавить товар

1. Положите фото в папку `images`.
2. Откройте `script.js`.
3. Добавьте объект товара в нужную категорию:

```js
{ name: "Название товара", price: "450 грн", image: "photo.jpg" }
```

## Как добавить новость

Добавьте новый объект в массив `newsPosts` в файле `script.js`.

## Telegram-заказы

Кнопка "Заказать" открывает чат `@MetaShop4` с готовым текстом:

```text
Добрый день, я хочу заказать [название товара]
```
